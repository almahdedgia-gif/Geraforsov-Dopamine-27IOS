CART3R Dopamine Demo — GitHub Actions

1. Create a new EMPTY repository on GitHub.
2. Extract this folder and upload the CONTENTS of CART3R_Dopamine_Demo
   to the repository root. Include the hidden .github folder.
3. Open Actions and enable workflows if prompted.
4. Commit/push to main, or choose "Build iOS demo" -> "Run workflow".
5. Open the completed run and download the artifact named
   Dopamine-Demo-iOS-Simulator.

This workflow builds an iOS Simulator app, not an installable iPhone IPA.
An iPhone IPA requires Apple code signing and a provisioning profile.
Never put passwords, certificates, or private keys in source code or a public repo.
This app is a visual simulation only; it does not jailbreak or modify iOS.
